Neste projeto foi colocado em prática os conceitos de Alocação Dinâmica de memória, TAD e Recursão. 
Este trabalho foi realizado em detrimento da matéria de Algoritmo e Estrutura de Dados 1, da grade do curso de Eng. de Software na UFAM. 
Dentro do arquivo principal há instruções de como compilar e executar o programa.

Consiste em um jogo de Campo Minado interativo no terminal. Seguindo os princípios básicos dos jogos de campo minado, ao iniciar a execução
do programa, a primeira entrada definirá a dificuladade da partida:

Se o jogador escolher 1, o campo será de 10x10 e terá 15 minas.

Se o jogador escolher 2, o campo será de 20x20 e terá 60 minas.

Se o jogador escolher 3, o campo será de 30x30 e terá 135 minas.
