Neste pequeno projeto foi colocado em prática os conceitos de manipulação de listas, TAD e ordenação em estrutura de dados.
Este trabalho foi realizado em detrimento da matéria de Algoritmo e Estrutura de Dados 1, da grade do curso de Eng. de Software na UFAM.
Dentro do arquivo principal há instruções de como compilar e executar o programa.

In this small project, the concepts of list manipulation, ADTs (Abstract Data Types), and sorting in data structures were put into practice.
This work was carried out as part of the course "Algorithms and Data Structures I" in the Software Engineering curriculum at UFAM.
Inside the main file, there are instructions on how to compile and run the program.
